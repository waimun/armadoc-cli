# Security

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the `armadoc` version (`npm ls -g armadoc`).

## Supported versions

Only the latest published `armadoc` and `@armadoc/crypto` get fixes.

## Scope

- The `armadoc` CLI and MCP server, including how they store the private key and credentials
- `@armadoc/crypto`, the encryption core shared with the web app
- The published npm packages and their provenance
